# Timer

[Source](../src/others/timer.hpp)

## 概要

経過時間をミリ秒単位で計測するタイマー。`chrono::steady_clock` を使用するため単調増加が保証される。

グローバルインスタンス `cl` が定義済みで、プログラム開始時から自動計測を開始する。

> **注意**: 呼ぶ回数が多いとかなり重くなる（2秒で約7×10⁷回程度が限界）。

## コンストラクタ

```cpp
Timer cl;
```

- デフォルトコンストラクタで初期化した時点から計測を開始する。

## 関数

### operator()

```cpp
double cl()
```

プログラム開始（または最後の `reset()` 呼び出し）からの経過時間をミリ秒で返す。

**計算量**

- $O(1)$（ただし頻繁な呼び出しはコスト大）

**使用例**

```cpp
while (cl() < 1950) {
    // 処理
}
```

---

### reset

```cpp
void cl.reset()
```

タイマーをリセットし、現在時刻から再計測を開始する。

**計算量**

- $O(1)$

**使用例**

```cpp
cl.reset();
// ここからの経過時間を計測
double ms = cl(); // リセット後の経過ミリ秒
```
